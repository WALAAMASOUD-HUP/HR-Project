📊 Human Resources Dashboard — Tableau
This project showcases an interactive Human Resources Dashboard built using Tableau to analyze employee demographics, performance, salary distribution, and employment trends across the organization.
________________________________________
🔍 Project Overview
The HR Dashboard is designed as a multi-page Tableau report containing:
1. Overview Dashboard
A high-level view of organizational workforce metrics, including:
•	Total active employees
•	Hiring vs Termination trends
•	Department headcount
•	Gender distribution
•	Education level and age segmentation
•	Employee performance across education groups
•	Location distribution (HQ vs Branch)
•	Salary insights (by gender & education)
•	Age vs Salary scatter for key management roles
![Image](https://github.com/user-attachments/assets/7a901fb2-ba9a-4946-8b1a-cdd2988684be)

2. Employee List Dashboard
An interactive employee directory featuring:
•	Employee ID
•	Demographics (age, education)
•	Role & department
•	Salary
•	Location
•	Hiring status
•	Length of employment
Includes dynamic filters allowing users to drill down and explore employee data.

________________________________________
🎯 Objectives
•	Provide actionable insights for HR decision-making
•	Identify hiring and retention trends
•	Analyze salary distribution and demographic patterns
•	Understand performance variation by education level
•	Support managerial reports with visually clear dashboards

________________________________________
🛠️ Tools & Technologies
•	Tableau Desktop
•	Data cleaning & preparation (Tableau Prep / Excel)
•	Custom color palettes and UI icons
•	Interactive filters, maps, scatterplots, and KPIs
________________________________________
📁 Dataset
Dataset includes anonymized HR data such as:
•	Employee ID
•	Age, gender, education level
•	Department & job role
•	Location (city, state)
•	Salary
•	Hire/termination dates
•	Employment length
